# Kaycee Ndukuba — Portfolio

Live: **https://kndukuba17-hub.github.io/**

Single-page interactive portfolio (Applied Data Scientist · Behavioural AI). Vanilla HTML/CSS/JS, no build step.

## Edit / tweak
1. Edit `index.html` (everything is in one file: `<style>`, markup, `<script>`).
2. Commit & push — GitHub Pages redeploys automatically in ~1 minute.

## Adding images / video (now that it's hosted — no sandbox limits)
- Drop files in `assets/` and reference them, e.g. `<img src="assets/my-image.png">` or `<video src="assets/demo.mp4" autoplay muted loop>`.
- Real brand logos, screenshots and MP4 loops all work here (they were blocked in the preview sandbox).
- Your graduation photo is in `assets/kaycee.jpg` (also embedded in the hero as a data URI for the binary-portrait effect).

## Structure
Hero (binary-portrait reveal) · Featured Work (scroll-driven visuals) · About (principles, competencies, toolkit) · Contact (message form).
